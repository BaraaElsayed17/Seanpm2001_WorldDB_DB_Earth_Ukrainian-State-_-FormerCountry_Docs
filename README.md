## Introduction

The **Seanpm2001 WorldDB** project aims to provide comprehensive data about various countries and regions, including those that no longer exist. The Ukrainian State is one such example. This documentation will guide you through the database's contents, how to set it up, and how to utilize it effectively.

## Project Overview

This project focuses on the Earth/Ukrainian State database, which is part of a larger initiative to catalog historical and geographical data. The database includes information on former countries, allowing users to explore the history and changes in territorial boundaries.

### Topics

- **Database**: A structured collection of data.
- **Earth**: The planet we inhabit.
- **Former Countries**: Nations that no longer exist in their previous form.
- **GPLv3**: The license under which this project is distributed.

## Database Structure

The database is organized into several tables, each representing different aspects of the former Ukrainian State. Here’s a brief overview of the main tables:

- **Countries**: Contains information about the country’s name, capital, and geographical coordinates.
- **Historical Events**: Documents significant events that occurred during the existence of the Ukrainian State.
- **Territorial Changes**: Tracks changes in boundaries over time.

### Example Table Structure

| Column Name         | Data Type     | Description                         |
|---------------------|---------------|-------------------------------------|
| id                  | INT           | Unique identifier for each entry    |
| name                | VARCHAR(255)  | Name of the country                 |
| capital             | VARCHAR(255)  | Capital city                        |
| coordinates         | POINT         | Geographical coordinates            |
| established_date    | DATE          | Date of establishment               |
| dissolved_date      | DATE          | Date of dissolution                 |
